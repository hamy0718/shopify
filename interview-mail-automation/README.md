# 面談打診メール自動化（面談統合ファイル × Outlook連携）

「★★【今のところ運用元】面談統合ファイル.xlsm」に組み込む、面談打診メールの
Outlook下書き一括作成マクロです（N列運用版）。

## 運用ルール（2026年8月〜）

| 列 | 意味 |
|---|---|
| O列 面談日／P列 時間 | 仮日程を入力しておく |
| N列 打診メール | 下書き作成時に自動で○（未打診の人は空欄） |
| Q列 日時確定 | 相手と確定したら手動で○ |

- ボタン1つで「O列の面談日が今日から対象日数（既定14日）以内・N列空欄・Q列空欄」の
  人全員のOutlook下書きを一括作成し、N列に○を付ける
- 宛先はエンジニアマスタのメールアドレス（社員番号→氏名の順で照合）
- メールは**即送信されません**。Outlookの「下書き」フォルダで確認してから送信
- アドレスが見つからない人はN列がオレンジ表示になり、結果ダイアログに列挙される
- N列に○がある行はスキップされるため、何度押しても二重作成されない

## 導入手順（初回のみ）

1. 面談統合ファイルを開き `Alt + F11` → 既に旧版のMailDraftModuleがある場合は
   右クリック→「解放」（エクスポートは「いいえ」）で削除
2. 「ファイル」→「ファイルのインポート」で `MailDraftModule.bas` を選択
3. `Alt + F8` → **`SetupInterviewMail`** を実行
   （「メールテンプレ」シートと「面談打診メール作成」ボタンが自動設置される）

## メールテンプレの差し込みタグ

| タグ | 内容 |
|---|---|
| `{氏名}` | D列 |
| `{面談予定日}` | O列（例：2026年8月12日(水)） |
| `{面談時間}` | P列（例：10:30） |
| `{企業名}` | F列 |
| `{担当営業}` | H列 |
| `{面談方法}` | K列 |
| `{社員番号}` | C列 |

対象日数は「メールテンプレ」シートB6で変更可能（30にすれば月内全員を一括対象にできる）。

## 注意事項

- デスクトップ版Outlookが必要（Web版のみでは動作しない）
- `.bas` はShift_JIS保存（日本語Windowsでそのままインポート可。GitHub上では文字化けして見える）
- 日付書式が外れたシリアル値のセルにも対応済み
- カレンダー連携マクロ（Module1_fixed_v2系・スレッド内提供）とは独立して動作する
