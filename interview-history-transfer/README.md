# 面談実績 → 履歴ブロック 自動転記マクロ

「面談統合ファイル.xlsm」のフォローアップシートで、当月分の面談実績（O～S列）を
W列以降の履歴ブロック（1回目～10回目）へ一括転記するマクロです。

月締め（`CloseMonth`）は O～S列をクリアするため、その前にこのマクロで履歴へ
記録しておくと、面談日・時間・形式・約定が数値データとして残ります。

## 列の対応

| 転記元（当月） | → | 転記先（履歴ブロック） |
|---|---|---|
| O列 面談日 | → | 日程 |
| P列 時間 | → | 時刻 |
| R列 形式 | → | 面談形態 |
| S列 約定 | → | 約定 |

履歴ブロックは W列（1回目）から4列ずつ、10回目（BG～BJ列）まで。
書き込み先は「最後に使われている回次の次」を自動で選びます
（1～7回目が空で8回目だけ埋まっている行は9回目に入ります）。

## 毎月の運用手順

1. 月別シート（例：8月）で **Calendar Update** … カレンダーを最新化
2. **履歴へ転記**（このマクロ） … 当月分を履歴ブロックへ記録
3. **月締め** … 実績シートを作成し、O～S列をクリア

> 2 と 3 の順番が逆になると、O～S列がクリアされた後では転記できません。

## 導入手順（初回のみ）

1. 面談統合ファイルを開き `Alt + F11`
2. 「ファイル」→「ファイルのインポート」で `HistoryTransferModule.bas` を選択
   （旧版が入っている場合は右クリック→「解放」で削除してからインポート）
3. `Alt + F8` → **`SetupHistoryTransfer`** を実行
   → 月別シートに「履歴へ転記」ボタンが設置される（Q1基準で右方向、月締めボタンの隣）

## 実行時の流れ

1. 対象月を入力（月別シートから実行すると、そのシートの月が初期値）
2. 転記範囲を選択
   - **はい** … 実施済みの行だけ（S列にマークがある行）
   - **いいえ** … 指定月の月末以前の面談日がある行すべて（＝月締めでクリアされる範囲と同じ）
3. 「転記する行／スキップする行」の内訳を確認 → 実行
4. 完了ダイアログに結果を表示

## 安全機構

- **二重転記の防止**：同じ日付が既に履歴ブロックに入っている行はスキップ
- **取り消し**：書き込んだ内容は `__HistoryTransferLog`（veryHidden シート）に記録され、
  `Alt + F8` → **`UndoLastHistoryTransfer`** で直前の転記をまるごと元に戻せる
- **事前確認**：書き込む前に件数の内訳をダイアログ表示
- **逆行の警告**：履歴の最終日より前の日付を追記する行があれば確認ダイアログに列挙
- **満杯の通知**：10回目まで埋まっている行はスキップし、氏名を列挙

## 収録マクロ

| マクロ名 | 内容 |
|---|---|
| `SetupHistoryTransfer` | 月別シートに「履歴へ転記」ボタンを設置（初回のみ） |
| `TransferMonthToHistory` | 本体。当月分を履歴ブロックへ転記 |
| `UndoLastHistoryTransfer` | 直前の転記を取り消す |
| `FixHistoryDateFormat` | O列と履歴の日程列に日付書式（yyyy/m/d）を設定。シリアル値（46244 など）のまま表示されている列を読めるようにする |

## 設定（モジュール冒頭の定数）

| 定数 | 既定 | 内容 |
|---|---|---|
| `UPDATE_INTERVIEW_COUNT` | `False` | `True` にすると転記後に L列（面談回数）を「n回目」へ自動更新 |
| `FIX_DATE_FORMAT` | `True` | 転記先の日付／時刻セルに表示形式を設定 |
| `MAX_LIST` | `8` | 確認ダイアログに名前を並べる最大件数 |

## 注意

- このマクロは O～S列をクリアしません。クリアは月締め（`CloseMonth`）が行います。
- カレンダーマクロ（Module1）とはヘルパー関数が重複しないよう、すべて別名の
  `Private` 関数として実装しています。同時に導入して問題ありません。
- ファイルは Shift_JIS(CP932)・CRLF です。エディタで開く場合は文字コードに注意。
