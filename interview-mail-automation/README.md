# 面談打診メール自動化（面談統合ファイル × Outlook連携）

「★★【今のところ運用元】面談統合ファイル.xlsm」に組み込む、面談打診メールの
Outlook下書き一括作成マクロです。

- フォローアップシートの **T列「次回予定」** に次回面談予定日を入力
- ボタン1つで、**予定日が近い未送信者全員のOutlook下書き** を一括作成
- 宛先は **エンジニアマスタのメールアドレス** を社員番号（または氏名）で自動参照
- 下書き作成済みは **BL列に「○」（緑）**、要対応（アドレス不明・予定日超過）は **オレンジ** で可視化
- メールは**即送信されません**。Outlookの「下書き」フォルダで目視確認してから送信します

## 導入手順（初回のみ・約2分）

1. 面談統合ファイルを開き、`Alt + F11` でVBAエディタを開く
2. メニュー「ファイル」→「ファイルのインポート」で `MailDraftModule.bas` を選択
   （プロジェクトツリーに `MailDraftModule` が追加されます）
3. `Alt + F8` でマクロ一覧を開き、**`SetupInterviewMail`** を実行

これで以下が自動で行われます：

- 「メールテンプレ」シートの作成（件名・本文・CC・対象日数を編集可能）
- フォローアップシートに BL列「打診メール」/ BM列「下書き作成日」の見出しを追加
- フォローアップシートに「面談打診メール作成」ボタンを設置

> 既存の「カレンダー更新」などのマクロには一切手を加えません。

## ふだんの運用

1. フォローアップシートの **T列「次回予定」** に次回面談予定日を入力する
2. 週1回（例：毎週月曜の朝）、**「面談打診メール作成」ボタン** を押す
3. 「T列の予定日が今日から14日以内（当日含む）かつBL列が未チェック」の人全員分の
   下書きがOutlookに作成され、BL列に「○」が入る
4. Outlookの「下書き」フォルダで内容を確認し、問題なければ送信する

- 対象日数（既定14日）は「メールテンプレ」シートのB6で変更できます
- 同じ人に二重に下書きが作られることはありません（BL列に○がある行はスキップ）
- 面談が終わって次の予定を入れるときは、T列に新しい日付を入れて **BL・BM列を消す** と
  次回分がまた対象になります

## メールテンプレの編集

「メールテンプレ」シートの黄色いセルを編集します。件名・本文には差し込みタグが使えます：

| タグ | 差し込まれる内容 |
|---|---|
| `{氏名}` | フォローアップシート D列 |
| `{面談予定日}` | T列の日付（例：2026年7月30日(木)） |
| `{企業名}` | F列 |
| `{担当営業}` | H列 |
| `{面談方法}` | K列 |
| `{社員番号}` | C列 |

## 色の意味（BL列「打診メール」）

| 表示 | 意味 |
|---|---|
| ○（緑） | 下書き作成済み（BM列に作成日） |
| オレンジ・空欄 | 要対応：エンジニアマスタにアドレスが無い、または予定日を過ぎて未送信 |
| 空欄 | 未送信（まだ対象日でないか、T列が未入力） |

## 注意事項

- デスクトップ版Outlookが必要です（Web版のみの環境では動きません）
- ファイルは「マクロ有効ブック(.xlsm)」のまま保存してください
- `MailDraftModule.bas` はShift_JISで保存しています（日本語Windowsでそのままインポート可）。
  GitHub上でプレビューすると文字化けして見えますが、インポートすれば正常です
- 完全自動送信（PCを触らず定時送信）にしたい場合は、Power Automate方式への移行が必要です
