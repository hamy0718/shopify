# 面談カレンダー マクロ（Module1 v9）

「面談統合ファイル.xlsm」の月別シート（6月・7月・8月…）を、フォローアップシートから
自動描画するマクロです。

## v9 の変更点（v8 からの差分）

### 1. 履歴ブロックからもカレンダーを描画する

v8 まではカレンダーの描画元が **O列（面談日）だけ** でした。そのため、実施済みの人の
O列を翌月の予定に上書きすると、次に Calendar Update を押した時点で当月カレンダーから
その人が消えていました（グレーの実施済み表示も消える）。

v9 では **W列以降の履歴ブロック（1回目〜10回目）** も描画元に加えます。

| 描画元 | 色 |
|---|---|
| O列の予定（S列にマーク） | グレー（面談済み） |
| O列の予定（Q列に○） | 緑（日時確定） |
| O列の予定（N列に○） | 水色（メール打診済み） |
| O列の予定（N・Q列とも空欄） | 黄（仮日程・未打診） |
| **履歴ブロック（日付が今日以前）** | **グレー（面談済み）** |
| **履歴ブロック（日付が明日以降）** | **緑（日時確定）** |
| 同じ枠に2人以上 | オレンジ |

これにより、**当月がまだ終わっていなくても、実施済みの人のO・P列を翌月の予定へ
上書きしてよくなります**（先に履歴へ転記しておくことが前提）。

左上の件数表示は、履歴から描いた分がある場合 `面談済み 47（うち履歴 12）` のように
内訳を表示します。

### 2. 年の照合

履歴には過年度の同じ月の面談も入るため、履歴からの描画では **年も照合** します。
月別シートには年の情報がないので、行4の曜日と行5の「1日」から年を推定します
（当年 → 前年 → 翌年 の順に、1日の曜日が一致する年を採用）。

O列からの描画は従来どおり月だけで判定します（挙動を変えないため）。

同じ行にO列と同じ日付の履歴がある場合は二重表示しません
（履歴へ転記した直後・月締め前の状態でも重複しません）。

### 3. 「シートへ反映」の安全化

`SyncCalendarToSheet`（シートへ反映ボタン）は、カレンダー上で動かしたセルの位置から
O・P列を書き換えます。v9 では **O列がそのシートの月でない行**（＝履歴ブロックから
描画された実績や、翌月の予定に切り替わった行）は書き換えません。動かした場合は
結果ダイアログに「履歴の実績なので動かしませんでした」として列挙します。

あわせて、逆反映時の年も曜日から推定するようにしました（v8 は常に今年固定）。

## 想定する運用（月をまたぐとき）

1. 月別シートで **Calendar Update**
2. **履歴へ転記**（`HistoryTransferModule` / 別フォルダ）で実施済み分をW列以降へ記録
3. 実施済みの人の **O〜S列をクリアして翌月の予定を入力**
4. 当月シートで Calendar Update → 実施済みの人は履歴からグレーで表示され続ける
5. 翌月シートで Calendar Update → 入力した翌月の予定が表示される
6. 当月が終わったら **月締め** → 実績シート作成 ＋ 残ったO〜S列をクリア

## 導入手順

1. 面談統合ファイルを開き `Alt + F11`
2. 左のツリーで旧 **Module1** を右クリック →「解放」（エクスポートは「いいえ」）
   - 解放せずにインポートすると `Module11` ができて名前重複エラーになります
3. 「ファイル」→「ファイルのインポート」で `Module1_fixed_v9.bas` を選択
4. 月別シートを開いて **Calendar Update** を押す

## 収録マクロ（v8 から変更なし）

| マクロ名 | 内容 |
|---|---|
| `UpdateCalendar` | 開いている月別シートを再描画（Calendar Update ボタン） |
| `CreateMonthSheet` | 6月シートを雛形に新しい月別シートを作成 |
| `SyncCalendarToSheet` | カレンダー上で動かした予定をO・P列へ書き戻す（シートへ反映ボタン） |
| `CloseMonth` | 月締め。実績シートを作成し、締める月以前のO〜S列をクリア |
| `InstallCalendarButtons` | 月別シートにボタンを設置し直す |

## 注意

- `CloseMonth` は「O列の日付が月末以前かどうか」だけで判定してクリアします。
  実施済みかどうかは見ないため、**まだ実施していない予定も消えます**。
  月内に実行しないでください。
- 月別シートの色凡例（AH列のメモ）は手入力です。v9 で履歴由来の表示が増えるため、
  必要なら「グレー＝面談実施済み（S列にマーク／履歴ブロックの過去日）」のように
  追記してください。
- ファイルは Shift_JIS(CP932)・CRLF です。
